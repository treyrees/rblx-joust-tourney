# Joust (working title)

A Roblox game: a recurring gauntlet of fast 1v1 jousts. Each pass is one committed mind-game
decision — hidden guard, televised aim, priced bluffing — resolved in a single tick, ending in a
Balance roll that decides who stays on the horse.

- **Design:** [docs/design/GAME_SPEC.md](docs/design/GAME_SPEC.md) — the canonical spec.
- **Agent guide:** [CLAUDE.md](CLAUDE.md) — invariants, conventions, current milestone.
- **Decisions:** `docs/design/decisions/` — append-only ADRs, numbered from 0001.

Successor to Grindstone Gladiators (`treyrees/rblx-auto-br`); the pivot rationale lives in that
repo's `docs/pivot/JOUST_CONCEPT.md`.

Current milestone: **M1 — the gray-box pass** (GAME_SPEC §13).
